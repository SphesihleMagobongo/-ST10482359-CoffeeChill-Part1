# CoffeeNChill - Daily Equipment Cleaning Checklist

| Equipment          | Task                                      | Frequency     |
| ------------------ | ----------------------------------------- | ------------- |
| Espresso machine   | Backflush group heads, purge steam wand   | Every shift   |
| Grinder            | Brush burrs, empty hopper                 | Daily close   |
| Fridges            | Check temps (<5C), wipe seals             | Daily open    |
| Sandwich press     | Degrease plates                           | After each use|
| Floors & counters  | Sanitise food-contact surfaces            | Every 2 hours |

Sign off in the shift log once complete. Report faults to the duty manager.
